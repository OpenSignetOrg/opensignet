## Install

:::note[Package availability]
Version 0.1.0 is not yet published to npm. Until it is, build from a source checkout of the
[public repository](https://github.com/OpenSignetOrg/opensignet).
:::

```bash
npm install @opensignet/eliza-plugin@0.1.0 "@elizaos/core@^1.0.0"
```

The plugin declares the `@elizaos/core: ^1.0.0` peer range.

## Register the plugin

```ts
import { openSignetPlugin } from '@opensignet/eliza-plugin';

export const character = {
  name: 'Research Agent',
  plugins: [openSignetPlugin],
};
```

## Runtime settings

The plugin reads its configuration through the runtime's settings. Inject credentials with the
runtime's secret facility, never in a character file, repository, command line, or log.

| Setting                 | Use                                                                                                                                                                                                                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Wallet key              | Signs registration, payments, and other wallet-authorized actions. Provide it only through the runtime secret store, and use a dedicated wallet that holds only the USDC it needs. The setting name is in the [package README](https://github.com/OpenSignetOrg/opensignet/tree/main/packages/eliza-plugin). |
| `OPENSIGNET_API_KEY`    | Agent-scoped key for DNS, email, and management actions.                                                                                                                                                                                                                                                     |
| `OPENSIGNET_API_URL`    | Defaults to `https://api.opensignet.com/api/v1`. Set only for another documented environment.                                                                                                                                                                                                                |
| `OPENSIGNET_NETWORK`    | `base` (default) or `base-sepolia`.                                                                                                                                                                                                                                                                          |
| `BASE_RPC_URL`          | Optional Base RPC. Defaults to `https://mainnet.base.org`.                                                                                                                                                                                                                                                   |
| `OPENSIGNET_REGISTRANT` | The domain owner as JSON (the [registrant fields](/api-reference/register/#domain-owner)). Registries require it for every domain the agent registers.                                                                                                                                                       |

Wallet-backed actions sign with the agent wallet key from these settings; the plugin does not use a
separate runtime wallet integration. Use a dedicated wallet that holds only the USDC the agent needs.

## Actions

| Available with                           | Actions                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No credentials                           | `QUOTE_AGENT_REGISTRATION`                                                                                                                                                                                                                                                                                                                                                                                                    |
| Agent wallet key                         | `REGISTER_IDENTITY`, `LIST_AGENT_EMAIL`                                                                                                                                                                                                                                                                                                                                                                                       |
| Agent wallet key or `OPENSIGNET_API_KEY` | `SEND_AGENT_EMAIL`, `SEND_AGENT_EMAIL_BATCH`, `DELETE_AGENT_EMAIL`, `GET_AGENT_EMAIL_USAGE`, `CONFIGURE_EMAIL_WEBHOOK`, `UPDATE_PRIMARY_EMAIL`, `CREATE_EMAIL_ALIAS`, `DELETE_EMAIL_ALIAS`, `GET_RENEWAL_STATUS`, `SET_AUTO_RENEW`, `GET_DNS_CAPABILITIES`, `LIST_DNS_RECORDS`, `CREATE_DNS_RECORD`, `UPDATE_DNS_RECORD`, `DELETE_DNS_RECORD`, `CHANGE_DNS_RECORDS`, `IMPORT_DNS_ZONE`, `EXPORT_DNS_ZONE`, `GET_SERVICE_PLAN` |

OpenSignet charges each renewal itself, from the account's OpenSignet wallet or saved card.
`SET_AUTO_RENEW` turns a domain's automatic renewal on or off ("turn off auto renew for
`<agent id>`"); turning it on from the wallet needs the owner's approval once on opensignet.com.

## Write registration requests

The actions read their inputs from the message text:

- Include the full domain, for example `research-agent.xyz`.
- Basename and ENS are off unless the request asks for them, for example "with Basename" or "with ENS".
- Set the term with a phrase such as "2 years" (1 to 10 years; one year by default).
- Do not name a plan in a registration request. Plans apply to the whole account and are bought
  from the dashboard or the [pricing page](https://opensignet.com/pricing).
- Domains renew automatically by default; say "without auto-renew" to register with it off.

Example intent:

```text title="Message"
Quote research-agent.xyz for 1 year with Basename.
```

`REGISTER_IDENTITY` pays as soon as it runs. Configure the character to run
`QUOTE_AGENT_REGISTRATION` first, show the total, and register only after explicit approval. The
quoted total includes every selected add-on.

## DNS and renewal changes

`CHANGE_DNS_RECORDS` and `IMPORT_DNS_ZONE` preview unless the request says "apply". To apply,
include `baseRevision:` with the 64-character revision returned by a fresh preview. Start with
merge mode and use replace only when the batch is the complete user-managed desired state.

Turning automatic renewal off should require explicit confirmation: the domain then expires unless
it is renewed. See
[registration](/guides/registration/), [DNS management](/guides/dns/), and
[renewals](/guides/renewal/) for the public safety contract these actions follow.
