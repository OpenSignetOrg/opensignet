title: MCP server

`@opensignet/mcp-server` runs over stdio and exposes the public OpenSignet lifecycle to
MCP-compatible clients. Install the package, or use a source build for development.

## Install

:::note[Package availability]
Version 0.1.0 is not yet published to npm. Until it is, build from a source checkout of the
[public repository](https://github.com/OpenSignetOrg/opensignet).
:::

```bash
npm install --global @opensignet/mcp-server@0.1.0
```

Or let an MCP client launch the pinned package directly:

```json
{
  "mcpServers": {
    "opensignet": {
      "command": "npx",
      "args": ["-y", "@opensignet/mcp-server@0.1.0"]
    }
  }
}
```

To run it from a source checkout, build from the repository root and point your MCP client's
stdio transport at the built entry point's absolute path:

```bash
pnpm install
pnpm --filter @opensignet/shared build
pnpm --filter @opensignet/sdk build
pnpm --filter @opensignet/mcp-server build
node packages/mcp-server/dist/index.js
```

This configuration starts the server read-only: it lists only tools that read data and never
pay, sign or change anything.

## Settings

Set these as environment variables of the MCP server process. Put secrets only in the MCP client's
protected secret controls, never in a committed configuration file.

| Setting                         | Purpose                                                                                                                                                                                       |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OPENSIGNET_ENABLE_WRITE_TOOLS` | Exactly `true` lists the write tools; unset or `false` keeps the server read-only. Any other value fails.                                                                                     |
| `OPENSIGNET_API_KEY`            | API key scoped to one identity, for DNS, email, renewal and management tools.                                                                                                                 |
| Wallet key                      | Signs registration payments. Use a dedicated wallet. The setting name is in the [package README](https://github.com/OpenSignetOrg/opensignet/tree/main/packages/mcp-server).                  |
| `OPENSIGNET_API_URL`            | Defaults to `https://api.opensignet.com/api/v1`.                                                                                                                                              |
| `OPENSIGNET_NETWORK`            | `base` (default) or `base-sepolia`.                                                                                                                                                           |
| `OPENSIGNET_REGISTRANT`         | The domain owner as JSON (the [registrant fields](/api-reference/register/#domain-owner)), used when `register_agent` is called without `registrant`. Registries require it for every domain. |

## Tools

Read-only tools are always listed. Write tools are listed only when
`OPENSIGNET_ENABLE_WRITE_TOOLS=true`.

| Group        | Read-only                                                                      | Write                                                                                                  |
| ------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| Discovery    | `check_domain_availability`, `quote_registration`, `lookup_agent`, `get_agent` |                                                                                                        |
| Registration |                                                                                | `register_agent_identity`                                                                              |
| Email        | `list_agent_email`, `get_agent_email_usage`                                    | `send_agent_email`, `send_agent_email_batch`, `delete_agent_email`, `configure_email_webhook`          |
| Addresses    |                                                                                | `update_primary_email`, `create_email_alias`, `delete_email_alias`                                     |
| DNS          | `get_dns_capabilities`, `list_dns_records`, `export_dns_zone`                  | `create_dns_record`, `update_dns_record`, `delete_dns_record`, `change_dns_records`, `import_dns_zone` |
| Renewal      | `get_renewal_status`                                                           | `set_auto_renew`                                                                                       |
| Plans        | `get_service_plan`                                                             |                                                                                                        |

## Renewal tools

| Tool                 | Arguments                      | Result                                                                                         |
| -------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------- |
| `get_renewal_status` | `agentId`                      | Whether the domain renews, how it is paid, its price, the charge window and what is in the way |
| `set_auto_renew`     | `agentId`, `enabled` (boolean) | Turns automatic renewal on or off and returns the domain's settings                            |

OpenSignet charges each renewal itself, 30 to 7 days before expiry, from the account's
OpenSignet wallet or saved card; no tool sends a wallet transaction for it. `get_renewal_status`
returns `ready` and, when something is in the way, `issue.code` and a plain `issue.message`.
Renewing from the OpenSignet wallet needs the owner's approval once, on opensignet.com; until then
`set_auto_renew` with `enabled: true` fails with `RENEWAL_APPROVAL_REQUIRED`. Code switches
renewal within that approval and never widens what the wallet may pay. Turning it off means the
domain expires unless it is renewed; keep that decision with the owner.

Both use `OPENSIGNET_API_KEY` (the identity's own key) or a wallet signature. Handle MCP `isError`
before consuming returned JSON. See [renewals](/guides/renewal/).

## Recommended usage policy

- Quote before every paid operation and show the owner the final amount.
- Require explicit confirmation before registration and before turning automatic renewal off.
- Preview DNS batches and imports before applying them.
- Use idempotency keys for email sends that can be retried.
- Scope API keys to one identity and keep wallet authorization outside model-visible context.
- Use a dedicated wallet that holds only the USDC it needs, and enable write tools only for clients
  you trust to ask for confirmation.

The source and complete package README are available in the
[public repository](https://github.com/OpenSignetOrg/opensignet/tree/main/packages/mcp-server).
