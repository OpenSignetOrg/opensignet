---
title: Renewals
description: How domains and plans renew from the OpenSignet wallet or a card, and how to read and switch renewal from code.
---

Domains renew automatically by default. OpenSignet charges each renewal when it falls due and
renews the domain at the registrar once. Nothing is deposited ahead of time and no onchain
setting is involved.

## How a domain renews

- **When:** the renewal is charged from 30 days until 7 days before the domain expires, so the
  registrar always has time. The domain's expiry then moves forward one year and the owner gets a
  receipt.
- **How it's paid:** from the account's OpenSignet wallet balance (USDC on Base), or from the
  account's saved card. The owner chooses per domain in the dashboard.
- **From the wallet:** the owner approves once, while signed in on opensignet.com, that the wallet
  may pay this domain's renewals. The wallet then signs each renewal only when it falls due, only
  to OpenSignet, and never above a quarter more than today's price. No funds are locked and no
  token allowance is granted.
- **If it can't be paid:** nothing is charged, and the owner is reminded 30, 7 and 1 day before
  the domain expires. A registrar refusal after payment is marked for refund, never retried blindly.
- **Turned off:** the domain expires unless it is renewed. The owner is still reminded before it
  does.

Plans renew the same way: a card plan renews through the card; a USDC plan renews from the
OpenSignet wallet within the owner's approval, charged from 3 days before the plan's period ends,
with reminders 14, 7 and 1 day before. Plans cover the whole account and are changed by a person
on opensignet.com.

## Read the renewal

```http
GET /api/v1/agents/:id/renewal
```

Use an API key scoped to the identity, a wallet request signature from the owning account, or the
owner's signed-in session.

```json
{
  "agentId": "11111111-1111-4111-8111-111111111111",
  "domain": "northwind.ai",
  "expiresAt": "2027-11-21T00:00:00Z",
  "autoRenew": true,
  "method": "wallet",
  "price": "79000000",
  "chargeWindow": { "opensAt": "2027-10-22T00:00:00Z", "closesAt": "2027-11-14T00:00:00Z" },
  "wallet": { "address": "0x…", "balance": "12000000", "approved": true },
  "cardSaved": false,
  "ready": false,
  "issue": {
    "code": "wallet_balance_low",
    "message": "The OpenSignet wallet holds less USDC than the renewal costs. Add USDC before the renewal is due."
  }
}
```

Amounts are USDC atomic units (6 decimals) as strings; `price` is one year at the registrar's price.
`ready` is true when nothing stands in the way. Otherwise `issue` names the first thing to fix:

| `issue.code`          | Meaning                                                        |
| --------------------- | -------------------------------------------------------------- |
| `not_registered`      | The domain is still being registered.                          |
| `auto_renew_off`      | Automatic renewal is off.                                      |
| `price_unavailable`   | The renewal price can't be read right now; nothing is charged. |
| `approval_needed`     | The owner hasn't approved the wallet to pay this renewal yet.  |
| `wallet_balance_low`  | The wallet holds less USDC than the renewal costs.             |
| `balance_unavailable` | The wallet balance can't be read right now.                    |
| `card_missing`        | Renewals are paid by card and no card is saved.                |

## Switch it on or off

```http
POST /api/v1/agents/:id/domain/auto-renew
POST /api/v1/agents/:id/domain/auto-renew/off
```

Both accept the same three ways in and return the domain's settings. Turning renewal on from code
works within the owner's approval: until the owner has approved the wallet once on
opensignet.com, an API key or wallet signature gets `409 RENEWAL_APPROVAL_REQUIRED`. Code can
never widen what the wallet may pay. A domain renewed by card needs a saved card
(`409 CARD_UNAVAILABLE`).

## SDK

```ts
const renewal = await openSignet.getRenewal(agentId);
if (!renewal.ready) console.log(renewal.issue?.message);

await openSignet.setAutoRenew(agentId, false);
await openSignet.setAutoRenew(agentId, true);

const plan = await openSignet.getServicePlan(agentId);
console.log(plan.renewal?.periodEnd);
```

The [MCP server](/sdk/mcp/) offers `get_renewal_status` (read-only) and `set_auto_renew` (a write
tool). The [framework integrations](/frameworks/agentkit/) expose the same reads, and AgentKit,
ElizaOS and LangChain (as a host opt-in) the switch.

## Monitor

Read `ready` and `issue` regularly, or before `chargeWindow.opensAt`, and act on the message. Keep
an independent expiry alert for production identities.
