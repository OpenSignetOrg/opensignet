---
title: Identities API
description: List the identities your wallet holds, read one by ID, and read or switch its renewal.
---

Identity data is private. There is no public registry, search or lookup of someone else's
identity; every read below is limited to the identities the caller owns.

## Look up by wallet

```http
GET /api/v1/agents/by-wallet/:wallet
```

The wallet must be a valid EVM address. A wallet can hold more than one identity, so handle an
array response rather than assuming a single record.

The caller must be authenticated as that wallet: a wallet request signature from it, or a
signed-in session of the account that holds it. Another wallet is rejected, and an API key scoped
to one identity is rejected with `403` because it cannot list a wallet's identities.

## Get by ID

```http
GET /api/v1/agents/:id
```

This endpoint is authenticated; there is no anonymous lookup of an identity. An API key scoped to the
identity can read it, and so can a signed-in session of the account that owns it. HTTP `200`
returns the identity record. A missing identity, or one the caller cannot access, returns `404`;
missing authentication returns `401`.

## Renewal

```http
GET /api/v1/agents/:id/renewal
POST /api/v1/agents/:id/domain/auto-renew
POST /api/v1/agents/:id/domain/auto-renew/off
```

Read how the identity's domain renews (on or off, how it is paid, its price, the charge window and
the first thing in the way), and turn automatic renewal on or off. Turning it on from code works
within the owner's approval of the OpenSignet wallet; without it the API answers
`409 RENEWAL_APPROVAL_REQUIRED`. See the [renewal guide](/guides/renewal/).

## Plan

```http
GET /api/v1/agents/:id/plan
```

The limits the identity has from its account plan, and how the plan renews (`renewal` is `null` on
the free plan). Plans are changed by a person on opensignet.com.

## SDK

```ts
const held = await openSignet.getAgentsByWallet(walletAddress);
const identity = await openSignet.getAgentById(agentId);
const renewal = await openSignet.getRenewal(agentId);
await openSignet.setAutoRenew(agentId, false);
const plan = await openSignet.getServicePlan(agentId);
```

See [authentication](/api-reference/overview/#authentication) for how an account owns an identity
before calling protected endpoints.
